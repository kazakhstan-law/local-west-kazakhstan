# Жәнібек ауданы аумағында сайлау учаскелерін құру туралы

"Қазақстан Республикасындағы сайлау туралы" 1995 жылғы 28 қыркүйектегі Қазақстан Республикасы Конституциялық заңының 23-бабына, "Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы" 2001 жылғы 23 қаңтардағы Қазақстан Республикасы Заңының 33-бабына сәйкес және Жәнібек аудандық (аумақтық) сайлау комиссиясының келісімі бойынша, аудан әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Жәнібек ауданы аумағында сайлау учаскелерi қосымшаға сәйкес құрылсын.

<a id="p2"></a>

2. Осы шешімнің орындалуын бақылау аудан әкімі аппаратының басшысы Ж. К. Абдоловқа жүктелсін.

<a id="p3"></a>

3. Осы шешім алғашқы ресми жарияланған күнінен бастап қолданысқа енгізіледі.

**Аудан әкімі**

**М. Мұқаев**
