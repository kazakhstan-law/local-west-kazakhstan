# 2021 - 2023 жылдарға арналған Жәнібек ауданы Ұзынкөл ауылдық округінің бюджеті туралы

> *Ескерту. 01.01.2021 бастап қолданысқа енгізіледі - осы шешімнің 7-тармағымен.*

Қазақстан Республикасының 2008 жылғы 4 желтоқсандағы Бюджет кодексіне, Қазақстан Республикасының 2001 жылғы 23 қаңтардағы «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Заңына сәйкес Жәнібек аудандық мәслихат ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. 2021-2023 жылдарға арналған Ұзынкөл ауылдық округінің бюджеті тиісінше 1, 2 және 3 - қосымшаларға сәйкес, соның ішінде 2021 жылға келесі көлемдерде бекітілсін:

   1) кірістер – 25 529 мың теңге:

      салықтық түсімдер – 888 мың теңге;

      салықтық емес түсімдер – 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер – 0 теңге;

      трансферттер түсімі – 24 641 мың теңге;

   2) шығындар – 25 529 мың теңге;

   3) таза бюджеттік кредиттеу – 0 теңге:

      бюджеттік кредиттер – 0 теңге;

      бюджеттік кредиттерді өтеу – 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо – 0 теңге:

      қаржы активтерін сатып алу – 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер – 0 теңге;

   5) бюджет тапшылығы (профициті) – 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) – 0 теңге:

      қарыздар түсімі – 0 теңге;

      қарыздарды өтеу – 0 теңге;

      бюджет қаражатының пайдаланылатын қалдықтары – 0 теңге.

<a id="p2"></a>

2. 2021 жылға арналған Ұзынкөл ауылдық округінің бюджет түсімдері Қазақстан Республикасының Бюджет кодексіне, Жәнібек аудандық мәслихатының 2020 жылғы 23 желтоқсандағы №50-2 «2021 – 2023 жылдарға арналған аудандық бюджет туралы» (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде №6582 тіркелген) шешіміне сәйкес қалыптасады.

<a id="p3"></a>

3. 2021 жылға арналған Ұзынкөл ауылдық округінің бюджетінде аудандық бюджеттен берілетін субвенциялар түсімдерінің жалпы сомасы 24 641 мың теңге көлемінде ескерілсін.

<a id="p4"></a>

4. Жергілікті атқарушы органдарға қарасты мемлекеттік мекемелер ұсынатын тауарлар мен қызметтерді өткізуден түсетін ақшалар Қазақстан Республикасының Бюджет кодексі және Қазақстан Республикасының Үкіметі анықтаған тәртіпте пайдаланылады.

<a id="p5"></a>

5. 2021 жылдың 1 қаңтарынан бастап Қазақстан Республикасының еңбек заңнамасымен белгіленген мамандар лауазымдарының тізбесіне сәйкес, ауылдық жерлерде жұмыс істейтін денсаулық сақтау, әлеуметтік қамсыздандыру, білім беру, мәдениет, спорт, ветеринария, орман шаруашылығы және ерекше қорғалатын табиғи аумақтар саласының азаматтық қызметшілеріне қызметтің осы түрлерімен қалада айналысатын азаматтық қызметшілердің мөлшерлемесімен салыстырғанда лауазымдық айлықақылар 25 %-ға көтеру белгіленсін.

<a id="p6"></a>

6. Жәнібек аудандық мәслихаты аппаратының басшысы (Н.Уәлиева) осы шешімнің әділет органдарында мемлекеттік тіркелуін қамтамасыз етсін.

<a id="p7"></a>

7. Осы шешім 2021 жылдың 1 қаңтарынан бастап қолданысқа енгізіледі.
