# 2026-2028 жылдарға арналған Бөкей ордасы ауданы Ұялы ауылдық округінің бюджеті туралы

> *Ескерту. 01.01.2026 бастап қолданысқа енгізіледі - осы шешімнің 4 тармағымен.*

Бөкей ордасы аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. 2026-2028 жылдарға арналған Ұялы ауылдық округінің бюджеті тиісінше 1, 2 және 3 - қосымшаларға сәйкес, соның ішінде 2026 жылға келесі көлемде бекітілсін:

   1) кірістер – 46 179 мың теңге:

      салықтық түсімдер – 11 041 мың теңге;

      негізгі капиталды сатудан түсетін түсімдер – 0 теңге;

      трансферттер түсімі – 35 138 мың теңге;

   2) шығындар – 46 179 мың теңге;

   3) таза бюджеттік кредиттеу – 0 теңге:

      бюджеттік кредиттер – 0 теңге;

      бюджеттік кредиттерді өтеу – 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо – 0 теңге:

      қаржы активтерін сатып алу – 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер – 0 теңге;

   5) бюджет тапшылығы (профициті) – -0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) – 0 теңге:

      қарыздар түсімі – 0 теңге;

      қарыздарды өтеу – 0 теңге;

      бюджет қаражатының пайдаланылатын қалдықтары – 0 теңге.

<a id="p2"></a>

2. 2026 жылға арналған ауылдық округінің бюджет түсімдері Қазақстан Республикасының Бюджет кодексіне және Бөкей ордасы аудандық мәслихатының 2025 жылғы 25 желтоқсандағы № 34-1 «2026 – 2028 жылдарға арналған аудандық бюджет туралы» шешіміне сәйкес қалыптасады.

<a id="p3"></a>

3. Жергілікті атқарушы органдарға қарасты мемлекеттік мекемелер ұсынатын қызметтер мен тауарларды өткізуден түсетін ақшалар Қазақстан Республикасының Бюджет кодексі және Қазақстан Республикасының Үкіметі анықтаған тәртіпте пайдаланылады.

<a id="p4"></a>

4. Осы шешім 2026 жылдың 1 қаңтарынан бастап қолданысқа енгізіледі.

**Мәслихат төрағасы**

**Л. Қайырғалиева**

> *2025 жылғы 31 желтоқсандағы*
