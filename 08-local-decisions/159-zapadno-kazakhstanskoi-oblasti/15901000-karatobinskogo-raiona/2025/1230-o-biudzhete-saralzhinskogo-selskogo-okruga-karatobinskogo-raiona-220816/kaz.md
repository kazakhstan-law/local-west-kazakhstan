# 2026-2028 жылдарға арналған Қаратөбе ауданының Саралжын ауылдық округінің бюджеті туралы

> *Ескерту. 01.01.2026 бастап қолданысқа енгізіледі - осы шешімнің 6 тармағымен.*

Қазақстан Республикасының Бюджет кодексіне, Қазақстан Республикасының «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Заңына сәйкес Қаратөбе аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. 2026-2028 жылдарға арналған Қаратөбе ауданының Саралжын ауылдық округінің бюджеті 1, 2 және 3-қосымшаларға сәйкес, оның ішінде 2026 жылға келесі көлемдерде бекітілсін:

   1) кірістер – 53 044 мың теңге, оның ішінде:

      салықтық түсімдер – 3 692 мың теңге;

      салықтық емес түсімдер – 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер – 0 теңге;

      трансферттер түсімі – 49 352 мың теңге;

   2) шығындар – 53 044 мың теңге;

   3) таза бюджеттік кредиттеу – 0 теңге:

      бюджеттік кредиттер – 0 теңге;

      бюджеттік кредиттерді өтеу – 0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо – 0 теңге:

      қаржы активтерін сатып алу – 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер – 0 теңге;

   5) бюджет тапшылығы (профициті) – 0 теңге;

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) – 0 теңге:

      қарыздар түсімі – 0 теңге;

      қарыздарды өтеу – 0 теңге;

      бюджет қаражатының пайдаланылатын қалдықтары – 0 теңге.

<a id="p2"></a>

2. 2026 жылға арналған ауылдық округтың бюджет түсімдері Қазақстан Республикасының Бюджет кодексі, Қаратөбе аудандық маслихатының 2025 жылғы 25 желтоқсандығы № 35-3 «2026-2028 жылдарға арналған аудандық бюджет туралы» шешіміне сәйкес қалыптасады.

<a id="p3"></a>

3. 2026 жылы берілетін субвенция көлемі 13 397 мың теңге сомасында белгіленсін.

<a id="p4"></a>

4. 2026 жылға арналған бюджетке жоғары тұрған бюджеттен бөлінетін нысаналы трансферттердің түсуі ескерілсін.

   1) аудандық бюджеттен жалпы сомасы - 35 955 мың теңге.

<a id="p5"></a>

5. Жергілікті атқарушы органдарға қарасты мемлекеттік мекемелер ұсынатын қызметтер мен тауарларды өткізуден түсетін ақшалар Қазақстан Республикасының Бюджет кодексі және Қазақстан Республикасының Үкіметі анықтаған тәртіпте пайдаланылады.

<a id="p6"></a>

6. Осы шешім 2026 жылғы 1 қаңтардан бастап қолданысқа енгізілсін.

> *2025 жылғы 30 желтоқсандағы*  
> *№ 35-10 шешіміне 1-қосымша*
