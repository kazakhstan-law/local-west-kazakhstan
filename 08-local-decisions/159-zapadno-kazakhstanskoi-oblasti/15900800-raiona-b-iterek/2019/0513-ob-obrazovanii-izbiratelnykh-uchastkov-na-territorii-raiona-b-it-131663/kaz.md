# Бәйтерек ауданының аумағында сайлау учаскелерін құру туралы

Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі «Қазақстан Республикасындағы сайлау туралы» Конституциялық заңына, Қазақстан Республикасының 2001 жылғы 23 қаңтардағы «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Заңына сәйкес аудан әкімі ШЕШІМ ҚАБЫЛДАДЫ:

1. Бәйтерек аудандық сайлау комиссиясының келісімі бойынша әкімшілік-аумақтық құрылым шекараларының сақталуы ескеріле отырып Бәйтерек ауданының аумағында сайлау учаскелері осы шешімнің 1- қосымшасына сәйкес құрылсын.

2. Осы шешімнің 2-қосымшасына сәйкес Бәйтерек ауданы әкімінің шешімдерінің күші жойылды деп танылсын.

3. Бәйтерек ауданы әкімі аппаратының басшысы осы шешімнің әділет органдарында мемлекеттік тіркелуін, Қазақстан Республикасының нормативтік құқықтық актілерінің эталондық бақылау банкінде және бұқаралық ақпарат құралдарында оның ресми жариялануын қамтамасыз етсін.

<a id="p4"></a>

4. Осы шешімнің орындалуын бақылау Бәйтерек ауданы әкімі аппаратының басшысына жүктелсiн.

<a id="p5"></a>

5. Осы шешім алғашқы ресми жарияланған күнінен бастап қолданысқа енгізіледі.
