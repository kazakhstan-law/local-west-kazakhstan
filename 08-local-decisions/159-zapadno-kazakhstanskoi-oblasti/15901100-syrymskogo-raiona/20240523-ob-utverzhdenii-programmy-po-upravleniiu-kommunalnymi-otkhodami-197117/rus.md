# Об утверждении программы по управлению коммунальными отходами по Сырымскому району на 2024-2028 годы

В соответствии с подпунктом 1) пункта 3 статьи 365 Экологического кодекса Республики Казахстана Сырымский районный маслихат РЕШИЛ:

1. Утвердить программу по управлению коммунальными отходами по Сырымскому району на 2024-2028 годы согласно приложению к настоящему решению.

2. Настоящее решение вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

**Председатель маслихата**

**Ш.Дуйсенгалиева**

> *Приложение к решению*  
> *Сырымского районного маслихата*  
> *От 23 мая 2024 года № 20-23*
