# О создании областного координационного Совета по борьбе с коррупцией при акиме области

> *Сноска. Утратило силу решением акима Западно-Казахстанской области от 10.01.2001 № 3.*

Во исполнение Закона Республики Казахстан "О борьбе с коррупцией" и для реализации Поручений Президента Республики Казахстан, высказанных на совещании по вопросам борьбы с коррупцией 9 июня 1999 года, а также в целях координации деятельности исполнительных, правоохранительных органов и общественных объединений в вопросах борьбы с коррупцией Решил:

<a id="p1"></a>

1. Создать областной координационной Совет по борьбе с коррупцией при акиме области (состав прилагается, приложение 1).

<a id="p2"></a>

2. Областному координационному Совету ежемесячно заслушивать руководителей управлений, комитетов, департаментов, исполнительных и правоохранительных органов по исполнению Закона "О борьбе с коррупцией" согласно графику (приложение 2).

<a id="p3"></a>

3. Членам координационного Совета ежемесячно проводить прием граждан по вопросам борьбы с коррупцией согласно графику (приложение 3).

<a id="p4"></a>

4. Областному управлению информации и общественного согласия (Карагойшин) обеспечить системное информирование населения области о деятельности областного координационного Совета через средства массовой информации.

<a id="p5"></a>

5. Контроль за исполнением данного решения акима области возложить на заместителя акима области Кулшар М.И.

**Аким области**

**К.Джакупов**

> *Приложение N 1*  
> *к решению акима области*  
> *N 131 от 18 июня 1999 года*
