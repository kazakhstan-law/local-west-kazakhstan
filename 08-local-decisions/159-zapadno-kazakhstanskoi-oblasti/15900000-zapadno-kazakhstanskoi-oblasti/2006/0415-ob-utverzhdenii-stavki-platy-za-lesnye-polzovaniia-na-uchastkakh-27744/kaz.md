# 2006 жылға арналған мемлекеттік орман қоры телімдерінде орманды пайдаланған үшін төлемдер мөлшерін бекіту туралы

> *Күші жойылды - Батыс Қазақстан облыстық мәслихатының 30.03.2007 № 36-14 шешімімен.*

Қазақстан Республикасының "Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы" Заңына, Қазақстан Республикасының "Салық және бюджетке төленетін басқа да міндетті төлемдер туралы" Кодексіне (Салық кодексі), Қазақстан Республикасының Орман Кодексіне сәйкес облыстық мәслихат ШЕШІМ ЕТТІ:

<a id="p1"></a>

1. Мемлекеттік орман үлескілерінде орман жерлерін пайдаланған үшін төлем мөлшері бекітілсін:

   1) қосалқы орман материалдарын пайдаланған үшін төленім мөлшері (қосымша N 1);

   2) шабындық төлемінің мөлшері (қосымша N 2);

   3) орман қорының үлескілерін аңшылық шаруашылық қажеттілігі үшін пайдалану төленім мөлшері (қосымша N 3);

   4) орман қорының үлескілерін мәдени-сауықтыру, рекреациялық және спорт мақсаттарына пайдалану үшін төленім мөлшері (қосымша N 4);

   5) орман қорының үлескілерін ғылыми-зерттеу мақсаттарына пайдалану үшін төленім мөлшері (қосымша N 5).

<a id="p2"></a>

2. Орманды пайдаланғаны үшін қаражаттар жергілікті бюджетке жолдансын.

<a id="p3"></a>

3. Облыстық мәслихаттың 2006 жылғы 18 ақпандағы N 25-8 "2006 жылға арналған мемлекеттік орман қорының үлескілерінде орманды пайдаланған үшін төлемдер мөлшерін бекіту туралы" шешімі жойылсын.

<a id="p4"></a>

4. Осы шешім 2006 жылдың 1 қаңтарынан бастап күшіне енеді.
