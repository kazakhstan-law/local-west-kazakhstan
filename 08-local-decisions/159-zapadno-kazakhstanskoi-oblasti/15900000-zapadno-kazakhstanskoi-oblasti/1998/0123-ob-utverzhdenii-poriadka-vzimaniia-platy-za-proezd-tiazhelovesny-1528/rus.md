# Об утверждении порядка взимания платы за проезд тяжеловесных и крупногабаритных транспортных средств по автодорогам Западно-Казахстанской области

> *Сноска. Утратило силу решением акима Западно-Казахстанской области от 09.03.2004 № 11.*

Согласно постановлению Кабинета Министров Республики Казахстан № 316 от 20.04.1993 года «Об утверждении правил пользования автодорогами, дорожными сооружениями и порядка их охраны на территории Республики Казахстан» и в целях обеспечения сохранности автомобильных дорог области, РЕШИЛ:

<a id="p1"></a>

1. Поручить казенному предприятию «Оралавтодор» (Уразов), начиная с 20 января 1998 года, передвижение транспортных средств по автомобильным дорогам области осуществлять только в соответствии «Инструкции по пропуску крупногабаритных и тяжеловесных транспортных средств по автомобильным дорогам общего пользования», утвержденной Министерством транспорта и коммуникации Республики Казахстан и согласованной Министерством внутренних дел Республики Казахстан.

<a id="p2"></a>

2. Таможенному управлению по Западно-Казахстанской области (Джубаев), областной транспортной инспекции (Умбеталиев), областной дорожной полиции (Маковский) принять конкретные меры по запрещению движения крупногабаритных и тяжеловесных транспортных средств по автодорогам области общего пользования без «Специального разрешения» казенного прдедприятия автомобильных дорог.

<a id="p3"></a>

3. Казенному предприятию «Оралавтодор» (Уразов) совместно с областной дорожной полицией (Маковский), областной транспортной инспекцией (Умбеталиев) обеспечить функционирование контрольно-пропускных пунктов по следующим адресам:

   1. М-32 Самара-Шымкент 247 км (с. Погодаево)

   2. Р-246 Атырау-Уральск 375 км (п. Чапаево)

   3. ЗК-8 Подстепное-Илек 144 км

   4. ЗК-24 Уральск-Озинки 73 км (с. Таскала)

<a id="p4"></a>

4. Контроль за исполнением настоящего решения возложить на первого заместителя акима области Маючего А. Ф.

**Аким области**
