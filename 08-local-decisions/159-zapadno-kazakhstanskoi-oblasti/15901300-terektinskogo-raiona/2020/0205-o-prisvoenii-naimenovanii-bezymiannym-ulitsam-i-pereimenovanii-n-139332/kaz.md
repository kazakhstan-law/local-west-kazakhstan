# Теректі ауданы Подстепное ауылдық округі Подстепное ауылының атаусыз көшелеріне атау беру және кейбір көшелеріне қайта атау беру туралы

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Заңына және 1993 жылғы 8 желтоқсандағы «Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» Заңына сәйкес, Подстепное ауылы тұрғындарының пікірін ескере отырып және Батыс Қазақстан облыстық ономастикалық комиссиясының қорытындысы негізінде, Подстепное ауылдық округінің әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Теректі ауданы Подстепное ауылдық округінің Подстепное ауылының атаусыз көшелеріне келесі атаулар берілсін:

   «№19» көшесі - «Ақжайық» көшесі;

   «№46А» көшесі - «Халифа Алтай» көшесі;

   «Орталық саябаққа дейінгі атауы жоқ» көшесі - «Саябақ» көшесі.

<a id="p2"></a>

2. Теректі ауданы Подстепное ауылдық округінің Подстепное ауылының кейбір көше атаулары:

   «Животноводов» көшесі - «Ынтымақ» көшесі;

   «Мира» көшесі - «Алтын Орда» көшесі;

   «Ленина» көшесі - «Бәйтерек» көшесі;

   «Интернациональная» көшесі - «Алаш Орда» көшесі;

   «1 переулок» көшесі - «Азаттық» көшесі;

   «М.Маметова» көшесі - «Мәншүк Мәметова» көшесі;

   «Махамбета» көшесі - «Махамбет Өтемісұлы» көшесі;

   «А.Саламатова» көшесі - «Ауданбай Саламатов» көшесі;

   «Исатая» көшесі - «Исатай батыр» көшесі деп қайта аталсын.

<a id="p3"></a>

3. Подстепное ауылдық округі әкімінің орынбасары (С.Жолдыгалиев) осы шешімнің әділет органдарында мемлекеттік тіркелуін қамтамасыз етсін.

<a id="p4"></a>

4. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p5"></a>

5. Осы шешім алғашқы ресми жарияланған күнінен бастап қолданысқа енгізіледі.

**Подстепный ауылдық округінің әкімі**

**С. Мадиев**
