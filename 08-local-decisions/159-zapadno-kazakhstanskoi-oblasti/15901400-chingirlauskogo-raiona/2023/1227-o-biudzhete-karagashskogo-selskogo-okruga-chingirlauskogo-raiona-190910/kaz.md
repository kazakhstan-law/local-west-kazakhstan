# 2024-2026 жылдарға арналған Шыңғырлау ауданы Қарағаш ауылдық округінің бюджеті туралы

> *Ескерту. 01.01.2024 бастап қолданысқа енгізіледі - осы шешімнің 5-тармағымен.*

Қазақстан «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасы Заңының 6-бабы 1-тармағының 1) тармақшасына сәйкес, Шыңғырлау аудандық мәслихат ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. 2024-2026 жылдарға арналған Шыңғырлау ауданының Қарағаш ауылдық округінің бюджеті 1, 2 және 3-қосымшаларға сәйкес, соның ішінде 2023 жылға келесі көлемдерде бекітілсін:

   1) кірістер – 45 173 мың теңге:

      салықтық түсімдер – 1 920 мың теңге;

      салықтық емес түсімдер – 0 теңге;

      негізгі капиталды сатудан түсетін түсімдер – 0 теңге;

      трансферттер түсімі – 43 253 мың теңге;

   2) шығындар – 45 173 мың теңге;

   3) таза бюджеттік кредиттеу – 0 теңге:

      бюджеттік кредиттер – 0 теңге;

      бюджеттік кредиттерді өтеу –0 теңге;

   4) қаржы активтерімен операциялар бойынша сальдо – 0 теңге:

      қаржы активтерін сатып алу – 0теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер – 0 теңге;

   5) бюджет тапшылығы (профициті) – 0 теңге:

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) – 0 теңге:

      қарыздар түсімі – 0 теңге;

      қарыздарды өтеу – 0 теңге;

      бюджет қаражатын пайдаланылатын қалдықтары – 0 теңге.

<a id="p2"></a>

2. 2024 жылға арналған Қарағаш ауылдық округі бюджетінің түсімдері Қазақстан Республикасының Бюджет кодексіне сәйкес қалыптастырылады.

<a id="p3"></a>

3. 2024 жылға арналған Қарағаш ауылдық округі бюджетіне республикалық бюджеттен берілетін нысаналы трансферттердің жалпы сомасы 101 мың теңге ескерілсін:

   мемлекеттік бюджет қаражаты есебінен ұсталатын азаматтық қызметшілердің жекелеген санаттарының, ұйымдар жұмыскерлерінің, қазыналық кәсіпорындар жұмыскерлерінің жалақысын арттыруға – 101 мың теңге.

<a id="p4"></a>

4. 2024 жылға арналған Қарағаш ауылдық округі бюджетіне аудандық бюджеттен берілетін субвенция түсімінің жалпы сомасы 43 152 мың теңге көлемінде белгіленсін.

<a id="p5"></a>

5. Осы шешім 2024 жылдың 1 қаңтарынан бастап қолданысқа еңгізіледі.
